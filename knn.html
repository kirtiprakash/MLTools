01 / Begin with a question

How can a computer classify a flower it has never seen?

Suppose a botanist has already measured and labelled 50 flowers. When a new flower arrives, we could look at the most similar flowers in the collection and ask: Which type appears most often among its closest neighbours?

STEP 1 · REMEMBER

Keep the examples

Each known flower has two measured features and a known category. KNN keeps these labelled examples.

STEP 2 · COMPARE

Find the nearest K

Compute distances from the unknown flower to the examples, then select the K closest ones.

STEP 3 · VOTE

Make a prediction

The most common category among those K neighbours wins. Ties are possible.

Key distinction: KNN is supervised classification, because the existing examples have labels. K-Means is unsupervised clustering, where K refers to cluster centres rather than neighbours.

03 / Turn intuition into an equation

Distance is a choice, not a universal truth

Two observations have two coordinates. The gap between them can be measured along a straight line or by moving horizontally and vertically. Changing that rule can change which neighbours are selected.

Euclidean distance · L2

d₂(a,b) = √[(a₁ − b₁)² + (a₂ − b₂)²]

The shortest straight-line distance between two observations. Large coordinate differences are squared before combining.

Manhattan distance · L1

d₁(a,b) = |a₁ − b₁| + |a₂ − b₂|

The total distance travelled along the coordinate axes. Imagine walking through a rectangular city grid.

04 / From memorisation to generalisation

Which value of K should we choose?

K = 1

Every stored example can influence a tiny neighbourhood. Predictions can become sensitive to noise and isolated examples, giving very jagged decision boundaries.

K = all

Every prediction uses the entire labelled dataset. With uniform voting, all unknown points receive the global majority class, so local structure disappears.

Instead of guessing K, evaluate candidate values. The plot below uses leave-one-out validation: remove one labelled example, predict it using the others, and repeat for all observations. The plotted accuracy is a validation estimate, not an independent test score.

The chart compares K=1…25 when sufficient samples exist. The synthetic labels intentionally include some overlap and optional noise so different K values have meaningfully different performance. A tie is counted as a missed classification. The displayed maximum is a model-selection estimate, not an unbiased final test score. In a serious study, perform preprocessing separately inside each validation fold, avoid tuning on the test set, and reserve untouched test data for final evaluation.

Is K ≈ √n always correct?

No. The square-root rule is a rough heuristic, not an optimality theorem. Dataset geometry, label noise, number of features and chosen distance all matter.

Should K always be odd?

Odd K avoids simple equal-count ties for two-class uniform voting when each neighbour has one vote. It does not guarantee good accuracy or prevent every possible tie under other schemes.

06 / Think, predict, test

Five small challenges for students

Before opening each explanation, change the controls in the experiment and predict what will happen. The correct answers should come from observing the model, not memorising a rule.

Q1 · Why does K = 1 create a jagged boundary?

With only one neighbour, a single nearby point can change a prediction. Small islands form around individual observations. This flexibility can capture detail but can also fit noise.

Q2 · Why can K = all ignore the unknown point's location?

Under uniform voting, every prediction uses the same set of all training examples. Whichever class occurs more frequently wins everywhere. With distance-weighted votes, location can still matter.

Q3 · Will multiplying all age measurements by 10 always preserve KNN predictions?

No. In raw Euclidean or Manhattan distance, age then contributes more relative to the other feature, potentially changing which neighbours are nearest. Standardizing with training statistics removes the effect of a simple positive unit rescaling of a feature.

Q4 · Does odd K guarantee a better classifier?

No. Odd K may avoid equal-count ties in two-class uniform voting, but it does not guarantee good predictions. Choose K using an appropriate validation method.

Q5 · What is the difference between KNN and K-Means?

KNN uses existing labels to predict a label for an unknown point. K-Means does not require class labels; it partitions points into K clusters by repeatedly assigning points to cluster centres and updating those centres.

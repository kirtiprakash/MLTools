01 / Begin with a question

Can we predict the future with a straight line?

Imagine predicting an exam score from hours studied. Students studying for the same number of hours may obtain different scores. Regression finds a line that summarizes the overall relationship, rather than memorizing every observation.

STEP 1 · OBSERVE

Collect examples

Record study hours and exam scores for previous students.

STEP 2 · LEARN

Find the best line

Adjust the slope and intercept to reduce squared prediction errors.

STEP 3 · PREDICT

Estimate a new score

Insert a new student's study hours into the learned equation.

ŷ = b₀ + b₁x

What does the slope mean?

For ŷ = 20 + 7x, each additional hour predicts seven more marks. At zero hours, the predicted baseline is 20.

Try a prediction before the computer

For a student studying five hours:

ŷ = 20 + 7 × 5 = 55

If the actual score is 62, the residual is +7. The model underpredicts by seven marks.

This is a synthetic illustration, not a claim about real exam performance.

b₀ is the baseline prediction at x = 0; b₁ is the predicted change in y per additional unit of x. The residual is the difference between observation and prediction. Association is not necessarily causation.

03 / Make the mathematics visible

Why least squares?

For each observation, eᵢ = yᵢ − ŷᵢ. Positive and negative residuals could cancel, so we square them before averaging.

J(b₀,b₁) = (1/n) Σᵢ (yᵢ − b₀ − b₁xᵢ)²

Residuals become squares

Doubling a residual quadruples its squared contribution. This explains why outliers can pull the fitted line.

A tiny worked example

ActualPredictedErrorError²
4045−525
6055+525
MSE = (25 + 25)/2 = 25

The signed errors sum to zero, but neither prediction is correct.

The least-squares solution sets both partial derivatives to zero:

b₁ = Σᵢ(xᵢ − x̄)(yᵢ − ȳ) / Σᵢ(xᵢ − x̄)²
b₀ = ȳ − b₁x̄

R² = 1 − SSE/SST compares the model to the baseline predicting the mean. It can be negative for an arbitrarily chosen line and is undefined when all observed y values are identical.

04 / Learning by optimisation

Gradient descent: walk downhill

Instead of solving algebraically, repeatedly update the parameters in the direction that decreases the loss. Here we standardize x to make the steps easier to control.

∂J/∂b₀ = −(2/n)Σᵢeᵢ   ·   ∂J/∂b₁ = −(2/n)Σᵢxᵢeᵢ
bⱼ ← bⱼ − η ∂J/∂bⱼ

Updates use standardized x; the plotted regression line is converted back to original units.

Small steps towards the minimum

A one-parameter slice of the loss surface. The actual model updates two parameters.

What does the learning rate do?

Too small: progress is slow.

Suitable: the loss decreases towards the minimum.

Too large: updates can overshoot and diverge.

Try: Compare η = 0.05 and η = 1.1 after restarting. Why can a large learning rate cause divergence?

05 / Bridge from concepts to Python

Reproduce it in Python

Export your experimental data above, upload it to Google Colab, and run this code. It compares a manual solution with scikit-learn.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

df = pd.read_csv('regression_data.csv')
x, y = df.x.to_numpy(), df.y.to_numpy()
b1 = np.sum((x-x.mean())*(y-y.mean())) / np.sum((x-x.mean())**2)
b0 = y.mean() - b1*x.mean()
yhat = b0 + b1*x
model = LinearRegression().fit(x.reshape(-1,1), y)
print('Manual:', b0, b1)
print('sklearn:', model.intercept_, model.coef_[0])
print('MSE:', mean_squared_error(y, yhat))
print('R2:', r2_score(y, yhat))
plt.scatter(x, y)
order = np.argsort(x)
plt.plot(x[order], yhat[order], color='orange')
plt.xlabel('x'); plt.ylabel('y'); plt.show()

These metrics describe training fit, not generalization. For real prediction tasks, evaluate on unseen test data.

06 / Think, predict, test

Check your understanding

Why not minimize the sum of residuals?Positive and negative errors cancel. Squared errors avoid cancellation and penalize large deviations.
Does R² = 0.95 prove causation?No. It describes fit relative to a mean baseline, not causality.
What if all x values are equal?The slope is not uniquely identifiable. A constant prediction can still be fitted.
Why might gradient descent diverge?A learning rate that is too large overshoots the minimum repeatedly.
What happens when a linear model meets curved data?Systematic residual patterns reveal model misspecification; consider nonlinear features or another model.
